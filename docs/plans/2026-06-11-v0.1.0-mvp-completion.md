**Step 1: Implement BuiltinPolicyEngine**

```go
type BuiltinPolicyEngine struct {
    rules []PolicyRuleData
}

func (e *BuiltinPolicyEngine) Evaluate(ctx context.Context, input core.PolicyInput) (core.PolicyDecision, error) {
    // 1. Filter rules by tenant (injected at creation time)
    // 2. For each active rule (sorted by priority desc):
    //    a. Match condition against input (simple key-value match on action, resource.type, resource.value, actor.type, actor.id, context.data_classification)
    //    b. If matched, return the action's decision type
    // 3. Default: allow
}
```

Condition matching is simple JSON key-value: condition has fields like `{"action": "task.publish", "resource.type": "capability", "resource.value": "production_release"}`. All conditions must match for a rule to fire.

**Step 2: Implement PolicyService**

```go
type PolicyService struct {
    ruleRepo PolicyRuleRepo
}

func (s *PolicyService) Check(ctx context.Context, input core.PolicyInput) (core.PolicyDecision, error) {
    rules, err := s.ruleRepo.ListActive(ctx, input.TenantID)
    if err != nil { return core.PolicyDecision{}, err }
    engine := &BuiltinPolicyEngine{rules: rules}
    return engine.Evaluate(ctx, input)
}
```

### Task 7: Implement DispatchService (core data plane)

**Why:** This is the most critical missing piece. Design §5.7 and §11 define the Agent pull→claim→start→ack/nack flow with lease management.

**Files:**

**Step 1: Define DispatchService**

```go
type DispatchService struct {
    taskRepo     TaskRepo
    attemptRepo  TaskAttemptRepo
    queueDriver  QueueDriver
    policySvc    *PolicyService
    budgetSvc    *BudgetService
}

type PullResult struct {
    Task      *core.Task
    LeaseID   string
    ExpiresAt time.Time
}

func (s *DispatchService) PullTask(ctx context.Context, tenantID, mailboxID, agentID string) (*PullResult, error) {
    // 1. Fetch from queue driver
    // 2. Dispatch-time policy check (policySvc.Check)
    // 3. Budget reservation (budgetSvc.CheckAndReserve)
    // 4. Generate lease_id (ULID)
    // 5. Create task_attempt (attempt=increment, agent_id, lease_id, status=claimed)
    // 6. Update task status to claimed
    // 7. Publish task.claimed event
    // 8. Return PullResult with task + lease
}

func (s *DispatchService) StartTask(ctx context.Context, tenantID, taskID, leaseID string) error {
    // 1. Validate lease_id matches latest attempt
    // 2. Update task status claimed -> running
    // 3. Update attempt status to running
    // 4. Publish task.started event
}

func (s *DispatchService) TaskHeartbeat(ctx context.Context, tenantID, taskID, leaseID string) error {
    // 1. Validate lease
    // 2. Update attempt heartbeat_at
    // 3. Publish task.heartbeat event
}

func (s *DispatchService) AckTask(ctx context.Context, tenantID, taskID, leaseID string, resultRef string, usage *core.TokenUsage) error {
    // 1. Validate lease
    // 2. Settle budget (budgetSvc.Settle)
    // 3. Update task status running -> completed, set result_ref
    // 4. Update attempt finished
    // 5. ACK driver delivery
    // 6. Publish task.completed event
}

func (s *DispatchService) NackTask(ctx context.Context, tenantID, taskID, leaseID string, retriable bool, taskErr *core.TaskError) error {
    // 1. Validate lease
    // 2. Release budget (budgetSvc.Release)
    // 3. Update attempt failed
    // 4. If retriable: update task status failed -> retry_scheduled, publish events
    // 5. If not retriable: update task status failed -> dead_lettered, move to DLQ
    // 6. ACK original delivery (Janus owns the state now)
}
```

- AckTask: success, wrong lease, with token usage
- NackTask: retriable → retry_scheduled, non-retriable → dead_lettered, wrong lease

Use mock repos and mock queue driver. This is the most critical service.
